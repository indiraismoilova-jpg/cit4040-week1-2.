# Reading Time Calculator

Run these commands from the repository's root folder.

```bash
javac src/ReadingTime.java
java -cp src ReadingTime
```

Expected output:

```text
100 pages -> 200 min
500 pages -> 1000 min
800 pages -> 1760 min
```

A book of exactly 500 pages gets no fatigue adjustment because the rule applies only to books over 500 pages.
